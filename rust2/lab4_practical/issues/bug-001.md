# bug-001: CLI tag formatting is not readable

**Summary**
The `add` command prints tags without spaces, which makes the output hard to read.

**Steps to reproduce**
1. Run `files_index_cli add --path file.txt --tags tag1,tag2`.
2. Observe the output.

**Expected behavior**
Tags should be printed with a comma and a space: `tag1, tag2`.

**Actual behavior**
Tags are printed as `tag1,tag2`.

**Priority**
priority: low
