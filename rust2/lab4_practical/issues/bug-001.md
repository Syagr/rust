# Bug 001 — CLI: tags formatting

Коротко: При додаванні файлу `lab3_cli` виводить список тегів без пробілів між ними, наприклад `cat,holiday` замість `cat, holiday`.

Кроки для відтворення:
1. Встановити `FILES_INDEX_PATH` у форматі `json:./data/index.json`.
2. Запустити: `cargo run --manifest-path lab3/cli/Cargo.toml -- add --path C:\Images\photo.jpg --tags "cat,holiday"`
3. У консолі побачити: `Added: C:\Images\photo.jpg with tags cat,holiday`.

Очікувано: `Added: C:\Images\photo.jpg with tags cat, holiday`.

Пріоритет: Low

Посилання на виправлення:
- Виправлення виконано у [lab3/cli/src/main.rs](lab3/cli/src/main.rs) — зміна форматування виводу тегів.

Коментарі:
- Це косметична зміна для зручності читання логу де зміни не зачіпають зовнішню поведінку програми.
