# bug-002: JsonStore fails when parent directory does not exist

**Summary**
JsonStore fails to save the index if the parent directory of the index file does not exist.

**Steps to reproduce**
1. Set `FILES_INDEX_PATH` to `json:C:\\tmp\\missing_dir\\index.json`.
2. Run `files_index_cli add --path file.txt --tags tag1`.
3. Observe the error.

**Expected behavior**
The parent directory is created automatically and the index is saved.

**Actual behavior**
The command fails with an I/O error (directory not found).

**Priority**
priority: medium
