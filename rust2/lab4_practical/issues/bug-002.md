# Bug 002 — JsonStore: failure when parent directory missing

Коротко: При спробі зберегти індекс у файлі у директорії, якої не існує, запис падає з помилкою I/O.

Кроки для відтворення:
1. Встановити `FILES_INDEX_PATH=json:./nonexistent_dir/index.json`.
2. Виконати додавання: `cargo run --manifest-path lab3/cli/Cargo.toml -- add --path C:\Images\photo.jpg --tags "cat"`
3. Очікувано — створення директорії і збереження файлу; Фактично — помилка I/O: No such file or directory.

Пріоритет: Medium

Посилання на виправлення:
- Виправлення виконано у [lab3/core/src/store.rs](lab3/core/src/store.rs) — до запису файлу додано створення батьківських директорій.

Коментарі:
- Виправлення гарантує роботу у випадку, коли шлях для індексу вказаний у новій директорії.
