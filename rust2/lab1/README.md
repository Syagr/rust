# Лабораторна робота 1 — Оформлення Rust проекту та робота із Cargo

Проєкт: `lab1` (в папці `rust2/lab1`).

Опис: синхронна CLI програма `image_editor`, яка читає файл зі списком посилань або локальних шляхів до зображень, змінює їх розмір і зберігає в директорію, задану змінною середовища `MYME_FILES_PATH`.

Швидкий старт (PowerShell):

```powershell
cd C:\It\projects\rust\rust2\lab1
setx MYME_FILES_PATH "C:\tmp\lab1_output"
$env:MYME_FILES_PATH = "C:\tmp\lab1_output"
cargo run -- --files examples\images.txt --resize 300x200
```

Відповіді на контрольні питання (1.2):

- Що таке крейт у Rust?
  - Crate — одиниця компіляції і повторного використання коду в Rust: бінарний або бібліотечний модуль коду.

- Що таке cargo? Які проблеми він вирішує?
  - `cargo` — офіційний менеджер пакетів і інструмент збірки для Rust. Він керує залежностями, збіркою, тестами, публікацією на crates.io та створенням пакетів.

- Чим крейт відрізняється від пакета?
  - `crate` — одиниця коду, `package` — набір файлів з `Cargo.toml`, який може містити один або кілька crate-ів (наприклад, бібліотеку та бінарники).

- Які є типи крейтів?
  - Бібліотечні (`lib`) та бінарні (`bin`) крейти; також procedural macro крейти і інші спеціалізовані форми.

Якщо потрібно, додам тести, приклади використання або CI-конфіг для автоматичної збірки.
